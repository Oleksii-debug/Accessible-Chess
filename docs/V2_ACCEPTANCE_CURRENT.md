These observations record current truth; they are **non-binding** and do not create a new mandatory task order.

- **Chess core / PGN / positions.** Product has one substantial Position/GameTree/SAN/FEN/PGN authority with round-trip, nested variation, source-binding, malformed-input, resource-bound, concurrency and recovery coverage. PR #2091 is the current unfinished PGN save-snapshot/commit transaction slice and is not qualified or integrated yet.

No audit evidence supports replacing these with another parser or reading model. Final Windows acceptance remains outstanding.

- **Lawful bundled content.** Provenance/license-aware starter-content code and qualification exist. No audit evidence authorizes pirated or unlicensed commercial content. Final archive inclusion and owner acceptance remain required.
- **Keyboard / NVDA / Windows.** Keyboard routing, focus recovery, native dialogs, UIA evidence, semantic-copy probes and accessible-result gates are substantial, but machine evidence cannot set `NVDA_VERIFIED=YES`. The user-reported acceptance issues #730 and #691 remain authoritative.
