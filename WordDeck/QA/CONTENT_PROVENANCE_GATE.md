# WordDeck commercial content provenance gate

This directory contains the canonical machine-readable seam for the WordDeck commercial-content rights policy defined by `WD-MASS120-089-CONTENT-RIGHTS-PROVENANCE` and independently audited by `WD-MASS120-098-AUDIT-CONTENT-RIGHTS`.

`content_provenance_manifest.json` is intentionally empty at introduction time. An empty manifest does **not** clear existing Oxford-backed lexical/audio data, Tatoeba content, AI-assisted course assets, private books, or any other content family. It means no asset has yet been registered here as `CLEARED_PRODUCTION` under this contract.

Production rule: a public/commercial release inventory must be validated with `tools/validate_content_provenance_strict.py --manifest ... --inventory ... --notices ...`. The strict entrypoint reuses `validate_content_provenance.py` for common manifest/release invariants and adds the MASS089 origin-specific evidence policy. Missing permissions default to denial; exact SHA-256 identity and `CLEARED_PRODUCTION` are mandatory; release channel, expiry, dependency graph, review/hash binding and required notices must resolve. A missing manifest record, hash drift, unresolved required notice, quarantined/private/internal/retired dependency, unknown/NC right, or unsupported release channel fails the gate.

Origin-specific policy is also fail closed. In particular, a generic Oxford terms/license snapshot is not commercial permission: an Oxford-backed asset cannot be production-cleared without explicit OUP permission/license contract or scoped legal opinion. Tatoeba text requires source-export, license and attribution evidence; Tatoeba audio also requires its own audio-license/attribution evidence and an explicit source-text license. AI-assisted assets require material-input traceability plus an exact output hash. Production native audio requires recording ownership, master hash, speaker-release evidence, source-text dependency and explicit voice-cloning/AI-training declarations.

The engineering V0.2 candidate remains an engineering evidence package and is not converted into a commercial-rights PASS by this change. In particular, this gate does not invent an Oxford license, Tatoeba/audio clearance, contributor assignment, voice right, or legal opinion. Those must be registered from real evidence before a commercial release inventory can pass.

The additional `review.reviewed_content_hash_sha256` field binds the rights/originality/source review to the exact bytes/text under review. Changing `content_hash_sha256` without re-review therefore fails deterministically.
