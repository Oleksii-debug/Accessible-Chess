# Section 38 — тестова бібліотека зі справжніх партій Stockfish (NVDA)

**Статус:** технічний шлях і сценарій GitHub Actions підготовлено; це **не**
підтвердження готового EXE, повного розділу 38 чи фактичного проходження CI.
Архів GitHub Actions з'являється тільки після успішного виконання відповідного
кроку й зберігається 14 днів.

## Які саме матеріали

- Справжня початкова колекція з 32 шахових партій із оригінального архіву
  `official-stockfish/books: 2moves_v2.pgn.zip` на підтвердженому коміті.
- Вихідний ZIP, ліцензія CC0-1.0 та їх SHA-256 перевіряються до конвертації.
- Партії семантично перевіряє чинний PGN-парсер, записує чинний серіалізатор,
  а під час старту застосовує **тільки** наявний `acs.user_library_seed`.
- Відсутні мережеві звернення під час імпорту; жодні шахові правила не
  дублюються, жодні чужі книги/бази ChessBase не включаються.
- Ця добірка містить лише 32 короткі дебютні партії. **Не** називати її
  повною бібліотекою вправ чи матеріалом GM-рівня.

## Як підключити до готової Windows-збірки

1. У GitHub відкрийте PR №2494 або репозиторій Accessible-Chess, вкладку
   **Actions** і workflow **Revised Sections 37-42 Corpus and Visual Contracts**.
2. Успішний прогін має додати файл-артефакт з назвою
   `section38-owner-test-library-seed-windows-2025`. Якщо прогін
   `queued`, `failed` чи `cancelled`, готовий архів **не підтверджений**.
3. Скачайте артефакт із GitHub Actions. Розпакуйте його поруч із реальною
   готовою програмою, зберігши структуру
   `release-content/user-library-seed/manifest.json` і
   `release-content/user-library-seed/stockfish_real_opening_games.pgn`.
   `source-readback.json` — окремий інформаційний доказ, не кладіть його
   всередину каталогу `user-library-seed`.
4. Не замінюйте існуючу папку `user-library-seed` з власною колекцією.
   Якщо така папка вже існує — залиште її недоторканою.
5. Запустіть уже наявну **готову Windows EXE**-версію Accessible Chess.
   Стандартний імпорт `user_library_seed` сам перевіряє розміри, SHA-256,
   цілісність і публікує партії в базу. Відкрийте **Library** і знайдіть
   джерело **Official Stockfish opening corpus (32 real source games)**.

## Межі підтвердження

- Тести мають окремо перевіряти: справжні вихідні байти, SHA-256, рівно 32
  партії, перезапуск бази, повторне відкриття, незмінність source_id і
  відмову без публікації при пошкодженому джерелі.
- Ці тести не є людським NVDA-прийманням, не доводять готову Windows EXE-збірку,
  не означають імпорт EPUB/PDF/ChessBase, і не надають позначку **DONE** для 38.
