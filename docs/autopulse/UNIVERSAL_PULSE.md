# Universal AUTOPULSE message

Send the exact same message to every Accessible Chess project chat, regardless of role:

`СТАРТ. AUTOPULSE. Продовжуй.`

Meaning:
- recover live Drive + GitHub + own durable checkpoint;
- resume unfinished own work first;
- inspect current cross-lane ownership and avoid duplication;
- if previous run is terminal, choose the largest coherent unclaimed P0/P1 package in the permanent role lane;
- execute, test, push and publish durable handoff;
- do not wait for another chat merely because it has not finished or has not written a report;
- no useful work may remain chat-only.
