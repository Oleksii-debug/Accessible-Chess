# WordDeck v0.1 — перший робочий реліз

Цей пакет призначений для Windows 11 і роботи з клавіатури, зокрема з NVDA. Для запуску не потрібні Python, .NET SDK або інші засоби розробника.

## Запуск

1. Розпакуйте ZIP у звичайну папку, наприклад `WordDeck`.
2. Не переміщуйте окремо `WordDeck.exe` з папки пакета: поруч має залишатися папка `AudioPacks`.
3. Запустіть `WordDeck.exe`.
4. Після запуску фокус переходить на поточне англійське слово. Клавіша `Tab` переходить між стандартними елементами керування.

## Вибір рівня і колоди

У полі `Recall study scope` можна вибрати один із шести режимів: `All Oxford 5000`, `A1`, `A2`, `B1`, `B2`, `C1`. Дійдіть до поля клавішею `Tab`, виберіть значення стрілками й підтвердьте вибір.

У полі `Active Recall deck` вибирається колода поточного рівня. У кожному рівні працюють п'ять постійних колод. Швидке перемикання: `Ctrl+1` ... `Ctrl+5`.

Переміщення поточного слова в колоду: `Alt+1` ... `Alt+5`. `Ctrl+Z` скасовує останнє переміщення. Колоди одного рівня зберігають свій стан незалежно від інших рівнів.

## Основне навчання Recall

- `Ctrl+Right` — інше випадкове слово з поточної колоди.
- `Ctrl+Left` — також інше випадкове слово відповідно до поточного Recall-контракту.
- `Ctrl+T` — показати український переклад без переходу до іншої картки.
- `Ctrl+R` — повторно оголосити поточне англійське слово засобами екранного читача.
- `Ctrl+P` — відтворити локальну британську вимову.
- `Ctrl+Shift+P` — увімкнути або вимкнути автоматичну британську вимову при зміні картки.
- `Ctrl+S` — негайно зберегти прогрес.
- `Ctrl+K` — відкрити налаштування клавіатурних скорочень.
- `F1` — відкрити поточну довідку WordDeck.

Команди перемикання рівнів також можна призначити у вікні `Ctrl+K`; за замовчуванням окремі глобальні скорочення для A1/A2/B1/B2/C1 не задані, щоб не створювати конфліктів.

## Збереження і відновлення

Прогрес зберігається автоматично після основних змін і при нормальному виході. Дані користувача розміщуються в `%LocalAppData%\WordDeck`.

Основний файл стану: `state.json`. Резервна копія: `state.backup.json`. `Ctrl+S` створює явний контрольний запис поточного стану.

## Офлайн-вимова

Перший робочий пакет використовує локальні MP3 у `AudioPacks\oxford-3000-en-uk`. Для відтворення не потрібен інтернет і немає хмарного fallback.

Якщо для конкретного слова локальний MP3 відсутній або пошкоджений, WordDeck має повідомити про проблему текстом у статусі; навчання повинно продовжувати працювати. Не редагуйте конфігурацію або код вручну.

## Доступність

Основний Recall-інтерфейс використовує стандартні WinForms ComboBox/TextBox/MenuStrip, має доступні назви для рівня, колоди, англійського слова, українського перекладу та статусу й підтримує клавіатурний маршрут без обов'язкового використання миші.

Інженерні автоматичні перевірки доступності та клавіатурного контракту не є заміною реальної перевірки NVDA на конкретному комп'ютері. Після отримання релізу рекомендований наступний практичний крок — короткий перший запуск із NVDA.
