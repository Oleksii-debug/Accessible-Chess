# WordDeck v0.2 — інженерний кандидат Foundation

Цей ZIP є кандидатом наступної версії WordDeck для Windows 11. Він НЕ замінює вже прийнятий WordDeck V0.1 і не означає незалежний фінальний PASS.

## Запуск

1. Розпакуйте весь ZIP у звичайну папку. Шляхи з пробілами та кирилицею підтримуються.
2. Не переносіть окремо лише `WordDeck.exe`: залиште поруч усі файли й папку `AudioPacks`.
3. Запустіть `WordDeck.exe`. Права адміністратора не потрібні.
4. Усі основні навчальні дії мають клавіатурний маршрут; миша не є обов'язковою.

Особистий прогрес зберігається поза програмним ZIP у `%LOCALAPPDATA%\WordDeck`, тому заміна чистого ZIP не повинна навмисно стирати навчальний стан.

Коли фокус на `Current English word`, `Down Arrow` показує наступну картку, а `Up Arrow` повертає реально попередню показану придатну картку. У перекладі, ComboBox, меню, діалогах та інших стандартних елементах стрілки зберігають нативну поведінку. `Ctrl+T` відкриває переклад, `Ctrl+R` повторює англійське слово, `Ctrl+P` відтворює локальну британську вимову. Поточні призначення клавіш завжди дивіться через `F1` або `Tools > Keyboard shortcuts`.

## Spelling та Adaptive Coach

Spelling відкривається поточною призначеною клавішею або через `Tools`. У стандартній конфігурації це `Ctrl+Shift+S`. Відповідь вводиться з клавіатури та підтверджується `Enter`.

Порожній або лише пробільний `Enter` не є навчальною спробою і відсікається до зміни статистики. Це також захищає від випадкового швидкого другого `Enter` після правильної відповіді. Adaptive Coach використовує збережену статистику й детерміновані пороги; показ відповіді та підказки не вважаються чистою першою спробою.

Закриття вікна — стандартним `Alt+F4`.

## Sentence Spelling / Sentence Coach

Sentence Spelling відкривається поточною призначеною клавішею або через `Tools`; стандартно — `Ctrl+Shift+E`. Вводяться потрібні англійські форми; порядок слів не оцінюється. Порожній `Enter` не змінює статистику.

Runtime, імпорт, SQLite-індексація, структурні обмеження, provenance і license-перевірки інтегровані. Однак цей ZIP **не заявляє, що містить фінальний production SentencePack**. Якщо незалежно прийнятого EN-UA SentencePack немає, програма не повинна вигадувати його або падати; валідований пакет можна встановити через передбачений імпорт.

## Повний особистий профіль

`Ctrl+Alt+E` / `File > Export personal progress profile` використовує єдиний профіль і переносить особистий навчальний стан **Recall + Spelling + Sentence**. Канонічний Oxford-корпус і AudioPack у profile JSON не копіюються.

`Ctrl+Shift+I` / `File > Import personal progress profile` імпортує через unified profile service з перевірками сумісності та recovery-захистом перед заміною даних. Несумісний профіль має відхилятися без тихої втрати поточного стану.

## Приховування та reset

`Ctrl+Delete` приховує слово зі звичайного Recall-навчання, але не видаляє канонічний запис, stable ID, локальне аудіо або валідні призначення до колод. Приховування зворотне.

`File > Reset Recall learning data` є саме Recall-reset: він не описується як глобальне очищення Spelling/Sentence. Перед ризиковим скиданням створюється recovery-матеріал.

## Британська офлайн-вимова

Для додаткових Oxford 5000 використовується прийнятий локальний AudioPack із 2 138/2 138 MP3. Відтворення не потребує хмарного fallback. Відсутнє локальне аудіо повинно давати читабельний статус, а не падіння програми.

## Безпека публічного ZIP

Публічний candidate ZIP не повинен містити `state.json`, backup/profile-файли користувача, `%LOCALAPPDATA%`-дані, токени, cookies, credentials, sessions, паролі або персональні абсолютні шляхи. Програма запускається як звичайний користувач без elevation.

## Доступність

Інтерфейс побудований на стандартних WinForms-контролах із доступними назвами й клавіатурними маршрутами. `F1` формує актуальну довідку з поточних призначень клавіш, включно зі Spelling і Sentence.

Автоматизований Windows UI Automation gate перевіряє реальні клавіатурні маршрути, фокус, нативні стрілки, профільні діалоги та тренувальні вікна. Це не є заміною фізичного ручного тесту з NVDA. Ручний NVDA PASS у цьому candidate не заявляється.

## Статус кандидата

Окремий файл `CANDIDATE_STATUS_UK.txt` містить межі того, що саме цей пакет заявляє і чого не заявляє. Accepted V0.1 зберігається окремо й цим кандидатом не перезаписується.
