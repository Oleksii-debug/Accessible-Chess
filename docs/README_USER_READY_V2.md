# User-ready Version 2

For release accounting, “machine-green” and “user-ready” are separate states.

A user-ready Version 2 candidate must combine successful automated release evidence with actual usable supplied content and complete keyboard/NVDA feedback for critical actions. A machine-green build can still fail human acceptance when the delivered product cannot be meaningfully exercised or when an action succeeds silently for the blind user.

Current status after Oleksii physical test start: `HUMAN_ACCEPTED=NO`, `NVDA_VERIFIED=NO`.
