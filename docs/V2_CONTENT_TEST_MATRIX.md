# V2 Packaged Starter Content Test Matrix

A fresh extracted candidate must prove at least one real packaged journey for each supported content surface:

- Book: discover -> open -> read -> navigate -> open position on board -> return to reading context.
- Training: discover -> open exercise -> submit/use supported interaction -> persist progress -> reopen/resume.
- PGN: discover -> open supplied PGN -> navigate moves/variations/comments -> return/close safely.
- Library: open supplied sample database -> browse -> search/filter -> open game -> return to results.
- Package relocation: repeat discovery/opening after extracting the same candidate to a different path.
- Accessibility: all discovery/open actions are keyboard reachable and expose meaningful NVDA semantics.
- Integrity: missing/corrupt supplied item does not partially mutate user data and produces a concise safe error.

A repository-only fixture or developer source tree is not packaged evidence.
