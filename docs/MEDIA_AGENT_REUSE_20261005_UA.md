# Повторне використання коду: медіа та універсальний агент

Дата: 2026-10-05. База: PR #2013, `b09043bc567300c7a2fb2695812d503d132ad075`.
Це доповнення наявного runtime, ModelGateway і ToolExecutor. Воно не створює
другого агента, шахового рушія, GameTree або джерела підтвердженої позиції.
Враховано чинні документи `CANONICAL_PRODUCT_VISION_AMENDMENT_2026-10-05.md`
і `MEDIA_INTELLIGENCE_AND_CHESS_AGENT_ARCHITECTURE.md` з main.

## Що додано

- Адаптовано OllamaProvider з Nika-Core до наявного ModelGateway. Реальний
  асинхронний HTTPX `/api/chat`, локальна адреса, перевірка відповіді, обмеження
  розміру, без автоматичного встановлення моделей. Закриття HTTP не означає
  підтвердженої зупинки обчислення на сервері.
- Адаптовано нормалізацію субтитрів Nika-Core через готовий pysubs2. Підтримуються
  локальні UTF-8/BOM SRT, VTT, ASS і SSA. Текст прив'язаний до джерела та ревізії,
  часовий контекст обмежений, застаріле джерело відхиляється.
- `speech_context.around_current_time` зареєстровано в тому самому ToolExecutor.
  Субтитри залишаються неперевіреним текстом джерела (`chessAuthority: false`).
- Додано виконуваний локальний шлях «файл → поточний контекст → запит агенту»
  через `python -m acs.media_context_cli`. Без `--ask` модель і мережа не потрібні.
- Виправлено перевірки Path у транскрипції та сховищі: реальний Path є
  PosixPath/WindowsPath. Виправлено помилковий набір контрольних символів у
  public_errors. Пошук SQLite виконується в потоці власника з'єднання.

## Готові зовнішні компоненти

Встановлено і перевірено `pysubs2==1.8.1` та `httpx==0.28.1`.
Це фіксовані перевірені версії, не твердження про найновіші релізи.
Ліцензії MIT із завантажених wheels і SHA-256 артефактів збережено в
`docs/third-party/media-agent/`. Залежності опційні; wheels і моделі не включено.

- [pysubs2](https://github.com/tkarabela/pysubs2),
  [API 1.8.1](https://pysubs2.readthedocs.io/en/1.8.1/api-reference.html): готові
  кодеки субтитрів, зняття службового форматування через plaintext.
- [HTTPX async](https://www.python-httpx.org/async/) і
  [Ollama chat](https://docs.ollama.com/api/chat): транспорт локальної моделі.
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper): наявний адаптер
  збережено; виправлено передавання реального локального Path. Модель не
  завантажувалася, якість справжнього STT не підтверджена.
- [fenshot](https://github.com/scoriiu/fenshot): розглянуто як кандидата для
  BoardVisionPort. Не інтегровано без перевірки артефакту моделі, походження
  та еталонних позицій. Розпізнане розташування фігур не є повним FEN.
- [YouTube IFrame API](https://developers.google.com/youtube/iframe_api_reference)
  залишається шляхом відтворення. Цей пакет не отримує звук чи відео з YouTube;
  обробляє надані користувачем локальні субтитри.

## Запуск

```console
python -m pip install -r requirements-media-agent.txt
python -m acs.media_context_cli "Урок.srt" --at-ms 90000
python -m acs.media_context_cli "Урок.vtt" --at-ms 90000 --json
python -m acs.media_context_cli "Урок.srt" --at-ms 90000 --ask "Що сказав коментатор?"
```

Для `--ask` потрібен окремо встановлений Ollama з локальною моделлю
`qwen3:8b` або зовнішнім `--config`, наприклад
`{"model":"qwen3:8b","base_url":"http://localhost:11434"}`.
Сервер повинен мати вимкнену хмару: `OLLAMA_NO_CLOUD=1` та перезапуск згідно з
[Ollama FAQ](https://docs.ollama.com/faq). Перевірка адреси й назви моделі в
адаптері сама по собі не доводить конфігурацію або поведінку сервера.

Межі: файл до 4 MiB, до 20 000 субтитрів, сумарний текст до 2 097 152 символів;
вікно до 60 секунд у кожен бік, відповідь до 100 сегментів / 12 000 символів.
Транскрипт не змінює шахову дошку чи вихідний файл.

## Сумісність і перевірка

Канонічні медіапосилання й медіакурсор належать Media Core #2003. UI має
передавати реальні source/revision/time через callback. CLI — виконуваний
інтеграційний вхід, а не завершене вікно YouTube для Windows.

Зміна `chess_agent_tools.py` стосується тільки `_register_library` і потоку
SQLite. Вона не замінює медіаблок #2057 або format tools #2090. При об'єднанні
потрібно зберегти обидва незалежні блоки. Host повинен створювати SQLite service
і запускати registry в одному робочому потоці; виконання великого синхронного
пошуку на GUI-потоці не кваліфіковано як чутливий до скасування сценарій.

Локально: 172 тести пройшли. Покрито реальні кодеки, Unicode, часовий контекст,
повний цикл агент → інструмент → відповідь із модельним fixture, HTTPX через
справжній loopback HTTP-сервер, відновлення сховища та протокол агента.
Faster-whisper перевірено з підміненою моделлю; реальні ваги Ollama/STT не
запускалися. Додано CI для Ubuntu 22.04 і Windows 2025, Python 3.12.10.
Локальна перевірка не є доказом проходження CI, ручного NVDA чи всього продукту.

Наявний convergence gate #2013 фіксує точні шляхи й blobs попереднього набору.
Його не послаблено. Після прийняття цього дочірнього пакета власник інтеграції
має сформувати нову явну baseline/перевірку для розширеного набору.

Наступні продуктові кроки: підключити tool до канонічного медіакурсора у
Windows host; кваліфікувати реальні локальні моделі; перевірити клавіатуру,
NVDA, seek і повернення до медіапозиції. Повний готовий Windows-реліз тут
не заявляється.
