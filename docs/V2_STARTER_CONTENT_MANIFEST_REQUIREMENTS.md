# V2 Starter Content Manifest Requirements

Every file/content item bundled for the Version 2 starter corpus must be traceable enough for redistribution audit and user support.

Record at minimum where applicable:

- stable content ID;
- title;
- author/creator;
- language;
- content type (book, lesson, exercise, PGN collection, game, database, position set, other);
- source/provenance;
- license/public-domain basis/permission;
- source URL or archival reference when applicable;
- package-relative path or Library identity;
- checksum for packaged static resources when practical;
- transformation/import notes when the original material was converted into the Accessible Chess semantic format.

Unknown or unverified redistribution rights mean the material is not eligible for the bundled release corpus.
