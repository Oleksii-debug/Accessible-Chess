Введення ходу

У режимі огляду NVDA: E — поле редагування, F — поле форми, B — кнопка. Enter у полі виконує хід.

Приклади: e4, Nf3, Bc4, O-O. Команди: u — undo, y — redo, l — останній хід, w — хід білих, d — хід чорних, x — очистити дошку, s — стандартна позиція, e — Stockfish.

Текстовий редактор позиції

Формат: W: K g1 Q d1 R a1 R f1 B c4 N f3 P e4 B: K g8 Q d8 N f6. Для композиції дозволено кілька однакових фігур; потрібен рівно один король кожного кольору.


Аналіз Stockfish

Дошка

Кнопка переводить фокус у режим дошки. Стрілки — поля, Enter/Пробіл — вибрати або виконати хід, Escape — повернутися в документ. Порожнє поле озвучується тільки координатою.

Дії

Довідка NVDA

H / Shift+H — заголовки. B / Shift+B — кнопки. E / Shift+E — поля редагування. F / Shift+F — поля форми. NVDA+Space — режим огляду/фокуса. На дошку входьте кнопкою «Увійти на дошку»; Escape повертає у документ.
